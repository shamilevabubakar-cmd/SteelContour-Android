# Стальной Контур — Android MVP

Исходный проект для Android Studio: Kotlin, Jetpack Compose, Room (SQLite).

## Реализовано
- Список объектов, сумма договора
- Локальное хранение объектов и операций без интернета
- Материалы, зарплата, прочие расходы, платежи заказчика
- Расчёт остатка платежей и предварительной прибыли
- История операций, удаление операций
- Денежные суммы хранятся в копейках (Long)

## Сборка
Откройте папку SteelContour в Android Studio (JDK 17, Android SDK 35), дождитесь Gradle Sync, затем Build > Build APK(s). Потребуется доступ к репозиториям зависимостей при первой сборке. Gradle Wrapper в архив не включён: Android Studio может использовать установленный Gradle 8.9. APK в архив не входит; сборка здесь не выполнялась.

## Ограничения MVP
Нет редактирования объекта, удаления объекта в интерфейсе, резервного копирования в файл, детализации материалов по количеству и цене, сотрудников по справочнику. Прибыль предварительная: сумма договора минус введённые расходы, а не движение денег. Автоматическое резервное копирование Android зависит от настроек устройства.
